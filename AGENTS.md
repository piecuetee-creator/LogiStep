# Project Instructions & Directives

## Persistent Directives

### 1. Build Verification & Deliverables
- **Always make and update build / app package after each change**: After making any functional or visual modification, always compile, build, and verify that all production artifacts and assets are cleanly compiled and ready for deployment, mobile distribution, or APK packaging.
- Ensure all mobile installation metadata, manifest assets, and build steps succeed without warnings or breakages (`compile_applet` & `lint_applet`).
